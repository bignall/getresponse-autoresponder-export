How to use it

About five minutes from start to finished export.

1. Get your API key

  1. Log in to GetResponse.
  2. Open Menu → Integrations and API → API.
  3. Click Generate API key, give it a name, and copy the key.

Treat the key like a password: anyone who has it can read your account.

2. Get the script

Download export_autoresponders.py into a folder of its own, or clone the repository:

git clone https://github.com/bignall/getresponse-autoresponder-export.git
cd getresponse-autoresponder-export

Check Python is installed with python3 --version (on Windows, py --version). If it isn't, install it from python.org.

3. Give the script your key

Pick one:

A .env file (easiest to reuse)

Create a file called .env in the same folder, containing:

GETRESPONSE_API_KEY=paste-your-key-here

An environment variable

# macOS / Linux
export GETRESPONSE_API_KEY=paste-your-key-here

# Windows PowerShell
$env:GETRESPONSE_API_KEY = "paste-your-key-here"

4. Run it

python3 export_autoresponders.py

On Windows use py export_autoresponders.py. You'll see something like:

Fetching autoresponders from GetResponse...
Exported 24 autoresponders from 3 list(s) to /home/you/exports/2026-11-13_142210
  - autoresponders.json
  - autoresponders.csv
  - html/index.html
  - txt
  - autoresponders_content.zip

Open html/index.html in your browser to look through the emails.

Options

OptionWhat it does
-o DIRSave to DIR instead of exports/<date-time>
-f json,csvOnly some outputs. Choices: json, csv, html, txt, zip
--campaign-id IDOnly one list. GetResponse calls lists "campaigns" in its API.
--status enabledOnly enabled (or disabled) autoresponders
--max us --domain example.comFor GetResponse MAX accounts (us or pl)
--include-rawAlso keep the untouched API data in the JSON
--csv-no-bodyLeave email content out of the CSV for a lighter spreadsheet
-vShow progress for each email

The JSON format

The JSON has two parts. autoresponders lists every email with its fields. sequences groups them by list in send order:

{
  "exportedOn": "2026-11-13T14:22:10+00:00",
  "count": 3,
  "sequences": [
    {
      "campaignId": "abc12",
      "campaignName": "newsletter_signups",
      "emails": [
        { "position": 1, "id": "Xy1", "dayOfCycle": 0, "delayDaysFromPrevious": 0 },
        { "position": 2, "id": "Xy2", "dayOfCycle": 2, "delayDaysFromPrevious": 2 },
        { "position": 3, "id": "Xy3", "dayOfCycle": 7, "delayDaysFromPrevious": 5 }
      ]
    }
  ],
  "autoresponders": [
    {
      "id": "Xy1", "name": "Welcome", "subject": "Welcome aboard!",
      "status": "enabled", "campaignId": "abc12", "campaignName": "newsletter_signups",
      "triggerType": "onday", "dayOfCycle": 0, "sendSettings": { "type": "signup" },
      "fromEmail": "you@example.com", "fromName": "You", "replyToEmail": "",
      "editor": "getresponse", "createdOn": "2023-01-05T10:00:00+0000",
      "html": "<html>...", "plainText": "..."
    }
  ]
}

Troubleshooting

HTTP 401
The key is wrong or was deleted. Generate a new one. On GetResponse MAX, also pass --max and --domain.
HTTP 403
Your plan may not include API access, or the key lacks permission.
HTTP 429 / slow progress
GetResponse limits how fast the API can be called. The script waits and retries automatically.
"No autoresponders found"
Check the account has time-based autoresponders. Action-based autoresponders were moved to Marketing Automation workflows, which this API endpoint does not include.
Accents look wrong in Excel
The CSV is UTF-8 with a byte-order mark, which recent Excel versions read correctly. Otherwise use Data → From Text/CSV and choose UTF-8.
