Get your autoresponders out of GetResponse

One small Python script downloads every follow-up email in your GetResponse account, with subject lines, content, send days and list order, in formats you can read, edit or import elsewhere.

Download the script How to use it

What you get

autoresponders.json

Everything, including each list's send order and the days between emails. Use it for imports.

autoresponders.csv

A spreadsheet of names, subjects, days and content. Opens in Excel or Google Sheets.

html/

One HTML file per email, plus an index.html to browse and preview them.

txt/

The plain-text version of each email, with its subject line on top.

autoresponders_content.zip

The HTML and TXT folders in one archive, for backups or sharing.

Why use it

  • A backup of emails you may have spent years writing.
  • A move to another platform. The JSON keeps each list's sequence order, ready for an importer. See moving to FluentCRM.
  • A review. Read the whole sequence in one spreadsheet instead of clicking through each email.

Requirements

  • Python 3.9 or newer. Nothing else to install.
  • A GetResponse plan with API access, and an API key.
Your exports are private. They contain your email content. Keep your API key out of shared files, and don't commit your exports/ folder to a public repository.
