Moving to FluentCRM

FluentCRM has no screen for importing emails. The companion FluentCRM Sequence Import script reads this export and rebuilds each GetResponse list as a FluentCRM Pro email sequence.

Merge tags

Personalisation tags differ between the two systems and must be converted, or subscribers will see the raw tag:

GetResponseFluentCRM
[[firstname]]{{contact.first_name}}
[[lastname]]{{contact.last_name}}
[[name]]{{contact.full_name}}
[[email]]{{contact.email}}
Unsubscribe link##crm.unsubscribe_url##

The importer converts these automatically, including fallbacks such as [[firstname "friend"]] → {{contact.first_name|friend}}, and lists any tag it doesn't recognise. GetResponse custom fields need matching FluentCRM custom fields.

Using the importer

  1. Export with this tool to get autoresponders.json.
  2. Create a WordPress Application Password for an administrator (Users → Profile).
  3. Run the importer without --apply to preview, then with --apply to create the sequences.
  4. Review the draft sequences in FluentCRM, send yourself tests, then add contacts.

Full instructions: How to use the importer. It needs FluentCRM Pro, because email sequences are a Pro feature.

Manual route (works today)

If you prefer to copy a handful of emails by hand:

  1. Open autoresponders.csv to see each list's emails in order with their days.
  2. In WordPress, go to FluentCRM → Email Sequences → Create New Sequence.
  3. For each email, add a sequence email, choose the Raw HTML editor, and paste the contents of the matching file in html/.
  4. Copy the subject line, and set the delay to the dayOfCycle value (days after joining the sequence).
  5. Replace merge tags using the table above, and send yourself a test.
