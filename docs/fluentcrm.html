Moving to FluentCRM

FluentCRM has no screen for importing emails, so the export is built to feed an importer that rebuilds each GetResponse list as a FluentCRM email sequence.

Merge tags

Personalisation tags differ between the two systems and must be converted, or subscribers will see the raw tag:

GetResponseFluentCRM
[[firstname]]{{contact.first_name}}
[[lastname]]{{contact.last_name}}
[[name]]{{contact.full_name}}
[[email]]{{contact.email}}
Unsubscribe link##crm.unsubscribe_url##

Check these against your own emails and FluentCRM's smart-code list in the editor. GetResponse custom fields need matching FluentCRM custom fields.

The importer (planned)

The importer will be a separate project that reads autoresponders.json and talks to FluentCRM's REST API on your WordPress site. It will:

  1. Run in dry-run mode by default and show what it would create.
  2. Create one email sequence per GetResponse list, skipping any that already exist.
  3. Add each email with its subject, HTML body and delay, with merge tags converted.
  4. Leave everything as a draft so you can review it before anyone receives it.
  5. List anything it could not convert automatically.
Before it can be built: email sequences are a FluentCRM Pro feature, and their API needs checking on a live site. The free plugin's source code has no email-sequence endpoints. You will need FluentCRM Pro and a WordPress Application Password for an administrator account.

Manual route (works today)

For a handful of emails, copying by hand is quick:

  1. Open autoresponders.csv to see each list's emails in order with their days.
  2. In WordPress, go to FluentCRM → Email Sequences → Create New Sequence.
  3. For each email, add a sequence email, choose the Raw HTML editor, and paste the contents of the matching file in html/.
  4. Copy the subject line, and set the delay from dayOfCycle or delayDaysFromPrevious, whichever the delay field measures.
  5. Replace merge tags using the table above, and send yourself a test.
